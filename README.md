# رابطتي – متجري الذكي (مشروع Flutter للأندرويد)

هذه الحزمة تعالج خطأ البناء السابق `Expected to find project root in current working directory`؛ فهي تحتوي الآن على جذر مشروع Flutter فعلي (`pubspec.yaml` و`lib/main.dart`) إضافة إلى واجهة HTML العربية الأصلية.

## البناء التلقائي عبر GitHub

1. أنشئ مستودع GitHub جديداً أو افتح مستودعاً مخصصاً لهذا التطبيق.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع (لا ترفع المجلد الخارجي كطبقة إضافية).
3. افتح تبويب **Actions**.
4. اختر **Build Rabitati Android APK** ثم **Run workflow**، أو انتظر البناء بعد رفع الملفات إلى `main`.
5. بعد نجاح البناء افتح صفحة تشغيل Workflow وانزل إلى **Artifacts** ثم نزّل `rabitati-smart-manager-apk`.
6. فك ضغط ملف Artifact لتحصل على `app-release.apk` وثبّته على هاتف Android.

## ما الذي يفعله التطبيق؟

- يفتح لوحة إدارة المنتجات العربية المرفقة داخل تطبيق Android.
- يدعم RTL ويشغّل JavaScript.
- تحفظ واجهة HTML المنتجات محلياً في مساحة WebView على الجهاز.

## تنبيه مهم حول البيانات

هذه لوحة مستقلة أولية، وليست متصلة بقاعدة بيانات متجر رابطتي/السويدي بروبنت أو SQLite أو Zite أو Whacka. لا تستوردها فوق مشروع المتجر الحالي، ولا تعتبر بياناتها المحلية بديلاً عن قاعدة بيانات المتجر. لا تحتوي الحزمة على أي قاعدة بيانات حالية أو منتجات/طلبات المتجر، ولا تغيّرها.

## ملاحظات

- يحتاج أول بناء إلى اتصال إنترنت لتنزيل Flutter وحزم Gradle.
- يتطلب البناء صلاحية GitHub Actions مفعّلة للمستودع.
- ملف APK الناتج غير موقّع بمفتاح نشر خاص؛ يصلح للاختبار والتثبيت المباشر، أما النشر الرسمي فيتطلب إعداد توقيع Android.
